
# Game Library

A personal video game collection management platform.

## About

Game Library is a web application designed to help users organize their video game collections, track their progress, manage platforms and rate their games.

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Git and GitHub

## Features

- User registration and login
- Personal game library
- Game management (CRUD)
- Platform management
- Game genres and ratings
- Search and filters
- Public and private libraries
- Dashboard and statistics
